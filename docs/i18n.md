# Internationalisation (WP-16)

Implements blueprint section 13.

- **Files:** `locales/{de,en}/*.ftl`. English is the reference: every other language must have the same files and the same message ids. `errors.ftl` additionally follows the error code registry (E-01).
- **Key constants:** `tools/codegen` generates `codeskimr_codes::i18n` (Rust, via `build.rs`) and `web/src/shared/i18n/keys.ts` (checked in, verified by the `codegen` CI job) from `locales/en/*.ftl`. Error messages are reached through `ErrorCode::message_key()` and are not part of these constants.
- **Completeness:** missing or extra files and keys, duplicate keys and colliding constant names fail the build of `codeskimr_codes` and `codeskimr_i18n`, and the `codegen` job. The tests of `codeskimr_i18n` also compare the `$variables` of every message between `de` and `en`.
- **Backend:** `codeskimr_i18n::Messages::format(lang, key, args)` embeds all files at build time and falls back to English (then to error `I18N-201`).
- **Adding a language:** add `locales/<lang>/` with all files. No code change.

Not yet part of this package: locale-aware number and date formatting (ICU4X), the language switch in the UI and the frontend loader.
