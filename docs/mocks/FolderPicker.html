2. Der Ordner-Dialog des Betriebssystems ist offen

Projekt hinzufügen

ORDNER
/pfad/zum/projekt
Ordner-Dialog geöffnet

Wähle im Fenster des Betriebssystems einen Ordner. Das Fenster kann hinter diesem Fenster liegen. Diese Seite wartet, bis du auswählst oder abbrichst.

3. Ordner gewählt: Pfad steht im Feld, nichts wird sofort angelegt

Projekt hinzufügen

ORDNER
/work/shop
Ordner übernommen. Prüfe den Pfad und klicke auf „Hinzufügen“.

Wann der Knopf erscheint: nur wenn der Server auf demselben Rechner läuft wie dein Browser und dort ein Desktop vorhanden ist. Bei einem Team-Server, über SSH oder ohne Desktop (z. B. Linux ohne Anzeige) fehlt der Knopf, und du gibst den Pfad wie bisher ein. Sicherheit: der Dialog wird nur nach Klick und mit Token ausgelöst und liefert nur den gewählten Pfad zurück, der Server liest nichts im Ordner, bevor du „Hinzufügen“ klickst. Abbrechen: Schließt du den Dialog, bleibt das Feld unverändert.
