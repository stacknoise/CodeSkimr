- **Length, fixed here:** three production functions were over 40 lines by this count, among them the `duplicates` function of WP-35 (42 lines): `conventions::duplicates::duplicates`, `parsing::pack::assemble` (43) and `parsing::symbols::new_symbol` (41). - **Length, left open:** seven test functions and the fixture `languages/typescript/tests/metrics.ts::rules`, and the different counting of check and clippy (issue #110).
- **Duplicates, left open:** 67 findings are mostly functions of 3 to 8 lines and parallel test functions at 100 % similarity, while `jscpd` (5 lines, 50 tokens) finds nothing. Too noisy for rule 4 of CLAUDE.md. Real finds that remain: `captures.rs::new` (85 %), `keystore.rs::install_platform_store` (90 %), `visibility.rs::by_name_rules`. Issue #110.

## For the product owner: the private reference (ADR 0017)

`tools/acceptance/holzbedarf.ps1` does four things: the counts of ADR 0017 (M1 criterion 3, step 2), the scan time on a real C# project (M1 criterion 5, step 3), the incremental scan (M2 criterion 5, step 4) and the sample of 20 usages (M2 criterion 4, step 5). It writes only to a folder outside the repository (`$HOME\codeskimr-abnahme-privat`), works on a copy of `src` for the watch test and never changes the reference.

```powershell
cd <CodeSkimr-Ordner>
git pull
.\tools\acceptance\holzbedarf.ps1 -Src 'C:\Pfad\zu\Holzbedarfskalkulation\src'
```

Result files in the output folder:

| File | Content | Goes where |
|---|---|---|
| `ergebnis.txt` | numbers and yes/no only (no names, no paths) | may be pasted into the project chat |

| `zaehlung-1.txt`, `zaehlung-2.txt` | full output of the counting test | stays local |
