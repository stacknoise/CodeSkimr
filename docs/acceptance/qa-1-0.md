# QA walk before 1.0

Run of 2026-11-15 on commit `ac9081d` (main after #383). Role: QA, no product code changed. The walk covers the corpora, all screens in three themes and two languages, and the MCP server over stdio and HTTP.

**Machine:** Linux container, 4 vCPU, release build. Absolute times are indicative (blueprint 16.1 names a mid-range laptop). Not covered: Windows and macOS (the product owner tests the Windows package), level 2 (no indexers installed in the container, so every scan reports the tools as missing, which is the intended message).

Legend: ✅ ok · ◐ ok with remarks · ❌ blocker

## Verdict

**No new blocker found.** The open blockers are the ones already tracked: the scan budget of 1 s per 100k lines on the reference machine (#107, Budgets thread), the Windows and macOS checks (#104, #131, #327) and the decisions of the product owner. New findings are all "after 1.0" (#399 to #402 below).

## 3. MCP

**stdio** (`codeskimr mcp`): `initialize`, `tools/list` (11 tools as in `docs/mcp.md`), `get_project`, `search_symbols`, `get_symbol`, `find_usages`, `impact_of_change`, `get_architecture`, `get_dependencies`, `find_constants`, `find_similar_code`, `check_conventions`, `rescan` all answer; errors are structured (`MCP-101`, `MCP-202`, `PRS-201`). `resources/list` and `prompts/list` return empty lists.

**HTTP** (`codeskimr serve`, `POST /mcp`, token from the launch-code exchange, keystore via gnome-keyring in the container): no token → 401; wrong `Host` or `Origin` → 403 `API-402`; 1 MiB limit → 413 `API-501`; all 11 tools with an explicit `project` work (usages with `limit` give the notice `MCP-501`, `rescan` of a small project 48 ms); without `project` the answer is `MCP-101` as documented.

Findings: #399 (numeric symbol id rejected), #400 (error answers outside the error format, wrong texts).

## 4. Other

- #402: the tool check reports "version not readable" for rust-analyzer when only the rustup shim exists.
- The `codeskimr serve` needs a keystore (`SEC-601` otherwise, by design); a headless Linux server needs a Secret Service. Worth a line in the user docs for 1.0.
