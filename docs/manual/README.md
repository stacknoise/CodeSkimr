# CodeSkimr user manual / Benutzerhandbuch

CodeSkimr scans code repositories and turns them into navigable documentation: a browser UI, a command line, a REST API and an MCP server for code agents.

CodeSkimr scannt Code-Repositories und macht sie als Dokumentation navigierbar: Browser-Oberfläche, Kommandozeile, REST-Schnittstelle und MCP-Server für Code-Agenten.
